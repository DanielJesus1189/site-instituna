# site-insti

Arquivo de festivais de tunas académicas — **Cartaz & Palmarés**.

Aplicação React + TypeScript + Tailwind CSS com listagem pública de festivais por ano,
cartazes, prémios, palmarés acumulado, mapa de festivais por distrito e área autenticada
para criar, editar e eliminar registos.

## Arrancar

```bash
cd frontend
npm install
cp .env.example .env.local   # ajusta VITE_API_BASE_URL para o teu backend
npm run dev
```

## Documentação

- [`frontend/README.md`](frontend/README.md) — API esperada, autenticação, estrutura,
  direção de arte e componentes de interface.

## Build

```bash
cd frontend
npm run build
npm run lint
```
